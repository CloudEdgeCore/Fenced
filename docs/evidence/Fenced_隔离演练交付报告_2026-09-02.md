## 技术要点

### 直接 runsc executor（PR #49）
新增 `-runsc-direct` 和 `-runsc-platform` 参数，让 OCI worker 可以不经过 containerd shim 直接调用 `runsc run`。适用于 shim 有兼容性问题的主机（WSL2、无 KVM runner）。

实现原理：
1. `ctr images mount <image> <mount>` 挂载镜像 rootfs（只读）
2. `cp -a` 复制到可写 bundle 目录（gofer 需要写权限）
3. 写完整 OCI spec（config.json）
4. `runsc run --platform=kvm --bundle=<bundle> <id>` 执行容器

### 跨类放置
两种 runtime 路径（Wasmtime 组件 + OCI 容器）都验证了跨运行时类放置：
- preferred 落入主池
- cordon 后备池接管（adapter pool 上的 hello runtime）
- 恢复后回到主池

### 环境适配
- 启用 WSL2 嵌套虚拟化（`.wslconfig` → `nestedVirtualization=true`）
- 安装 Ubuntu 24.04 + containerd + gVisor + PostgreSQL + pgvector
- `FENCED_RUNSC_DIRECT=1` 环境变量切换 direct runsc 模式
